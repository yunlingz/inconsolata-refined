This is regular text, this is italic, this is bold, and this is bold italic. Standard HTML elements select the matching font files automatically.

Use it on your website

Keep the stylesheet and font files together. Load the stylesheet, then apply the family to any element.

<link rel="stylesheet" href="./inconsolata-refined.css">

<style>
  .sample {
    font-family: 'Inconsolata Refined', monospace;
  }
</style>

<p class="sample">
  Regular <em>Italic</em> <strong>Bold</strong>
  <strong><em>Bold Italic</em></strong>
</p>
